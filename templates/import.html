Analyse:

Full analysis runs every enrichment Music Room has: cover art, streaming presence + ISRC, record label, and artist + label origin/decade — all from free music databases (Deezer, iTunes, MusicBrainz, Wikidata, optionally Discogs). It runs after the import finishes; MusicBrainz allows about one lookup per second, so a big batch takes a while. Stop any time — everything done so far is saved.

When a duplicate file is found:

A duplicate = byte-identical to a file already in your library that's still on disk. If the library's file is missing, the track is always relinked to the found copy (pure recovery — never deleted), whatever you pick here.

Also add to places (optional — everything goes to the Music Room regardless)

Existing files are skipped automatically, and so are byte-identical duplicates and Ableton project folders. Copy/move then files the just-imported tracks into Library/A/Artist/Album/… — move frees them from the source, copy leaves the originals. 


        


        
        

            
My productions

            

                Import your own tracks and their bounces/versions, each linked to the Ableton
                session it came from — so you can listen, compare and take notes like any record,
                then jump straight back into the right session to make the next version.
                Your files are never moved or changed — the Music Room only links to them.
            

            

                How to save your projects (it's just the normal Ableton way)
                

                    Group an album in a folder; each track is its own subfolder. Inside, every
                    Ableton session and its identically-named bounce
                    (Track 1 v2.als + Track 1 v2.wav) is one version —
                    bounce a new session under a new name to add a new version.
                

                
Album 1/                     ← the album — point Music Room here
  Track 1/                   ← one folder per track
    Track 1.als              ← a session …
    Track 1.wav              ← … its bounce (same name = one version)
    Track 1 v2.als           ← a new session = a new version …
    Track 1 v2.wav           ← … bounced under the same name
  Track 2/
    Track 2.als
    Track 2.wav

                

                    Point at an album (its track folders become the album's tracks) or a single
                    track folder. Ableton's Samples, Backup and
                    Project/Folder Info are skipped automatically; the un-stamped
                    .als is your current version.
