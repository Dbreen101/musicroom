Sound fingerprint
Recomputes the per-track audio fingerprint with A-weighted band loudness across 6 perceptual bands (sub / bass / low-mid / body / presence / brilliance) plus a vocal-likelihood score. Replaces the old bass/mid/treble bars (which always read ~85% bass) with corpus-relative values you can actually compare. Runs ~1 s per track in the background.

BPM refinement
The old tempo analysis snapped every BPM onto a coarse grid (a whole library collapses onto ~47 values — real 120/128 BPM tracks read as 117.5/129.2). This re-estimates every stored BPM with the corrected analyser (accurate to ~±0.5 BPM). Runs ~1–2 s per track in the background; stop any time — finished tracks keep their corrected value.

Import rekordbox analysis
Bring rekordbox's BPM & key in as a layer beside the Music Room's own. Export your rekordbox collection to an XML, choose it here, and each track's rekordbox analysis is matched (by file path, filename, then artist+title) and stored. The track panel then shows rekordbox by default with a flick to the Music Room's. Nothing else changes; re-import any time to refresh.
Import rekordbox genres, cues & colours
Already curated in rekordbox? Bring that work the other way — into the Music Room. From the same collection XML this pulls in genres, cue points (memory & hot, as timestamped notes) and the track colour. It's additive and safe: genres are added (never removed), cues skip ones you already have, and a colour only fills a record that has none — your own tags and tints are never overwritten. Preview first to see exactly what would change. (rekordbox MyTags aren't in the XML, so they can't be imported this way.)
Record labels
Looks up each track's release label via MusicBrainz (free, no key, ~1 s per track) and Discogs (better for electronic / vinyl — add a token in Settings to enable it). Skips tracks already labelled, tracks marked "Self released", and unknown tracks (no artist or title). Throttled to respect the API rate limits.

Strip "Original Mix" from titles + files
"(Original Mix)" / "(Original Version)" suffixes are noise — Spotify, MusicBrainz, Discogs and iTunes don't carry them, so leaving them on titles causes API lookups to miss. This walks every affected track, removes the tag from the DB title, writes the cleaned title into the audio file's embedded tags, and renames the file on disk (collision-safe). Other version tags ("Extended Mix", "Club Mix", "Album Version") are deliberately left alone — those are meaningful.

ISRC codes
Reads each track's embedded ISRC (the unique recording id) from its file and stores it in the background — it isn't shown anywhere. With an ISRC the DSP check, label lookup and artwork fetch can match a track exactly instead of guessing from artist + title. Local file read only, no network — fast. FLACs usually carry one; most MP3s don't.

DSP availability
Checks each track against Deezer + iTunes (free, no login, no Spotify rate limits). Tracks with an ISRC are matched exactly; the rest fall back to a tight artist+title search. Tracks already on Apple Music (from artwork) are counted for free. The result is stored so we never re-check per page load — tracks confirmed on no DSP show an "only here" chip on every track row. Unknown tracks are skipped.

Artist origins
Pulls each artist's origin (birthplace + country), gender, type, active-from year and genres from MusicBrainz + Wikidata, with a short Wikipedia bio. Free, no login, no AI — uses your ISRCs for exact matches where possible. Feeds the world map and cultural views. Unknown/untagged tracks are skipped.

Record label origins
Looks up each label's country, city/HQ, founding year and founder from MusicBrainz + Wikidata (+ a Discogs fallback if you've added a token). Free, no AI. "Self released" is skipped. Builds the label-geography map.
